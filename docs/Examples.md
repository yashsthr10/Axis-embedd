# Examples

Practical starter guides for common tasks.

## 1) Add a new API endpoint

1. Add request/response contract.
2. Add handler/controller entry point.
3. Add application service/use-case logic.
4. Add domain validation/rules if needed.
5. Add repository or integration calls.
6. Add tests and update `Codepath.md`.

## 2) Add a background worker

1. Define message/event schema.
2. Add worker consumer and idempotency checks.
3. Implement processing service.
4. Add retry/dead-letter behavior.
5. Add metrics/logging and tests.

## 3) Add a database migration

1. Write forward migration.
2. Write rollback strategy.
3. Validate data compatibility.
4. Deploy with migration sequencing rules.
5. Add regression checks.

## 4) Add a new feature module

1. Confirm module ownership in `Modules.md`.
2. Define dependencies in `Dependencies.md`.
3. Follow pattern guidance in `Patterns.md`.
4. Capture key decisions in `Decisions.md`.
5. Update docs and tests.
